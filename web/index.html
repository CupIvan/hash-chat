# hash-chat
#

hash-chat

Быстрый чат на хэшах. Сервер не видит сообщений — только хэши, порядок и цепочку.

#

Приглашение в чат

Подключение

Адреса hashchat и CAS. Для GitHub Pages нужны полные https-адреса.

Профиль

Логин обязателен, имя — по желанию. Профиль лежит в CAS, поэтому смена логина или имени создаёт новую личность.

Настройки чата

Пусто — использовать общие адреса из «Подключения».

Ссылка-приглашение

Код содержит чат и адреса API/CAS — приглашённому не нужно ничего настраивать вручную.
